🎯 Настройка донатов в StreamElements: полный гайд
1. Создай аккаунт
- Перейди на сайт StreamElements.
- Войди через Twitch / YouTube / Kick — что ты используешь для стримов.

2. Открой страницу Tip Settings
- В левом меню выбери Streaming Tools.
- Далее Tipping Settings (или My Tips → Settings).
Это раздел, где настраивается твоя страница донатов.

3. Подключи платёжную систему
StreamElements принимает донаты через:
✔ Stripe — лучший вариант
- Работает в Латвии
- Принимает Visa/Mastercard, Apple Pay, Google Pay
- Деньги выводятся прямо на Swedbank
- Комиссии ниже, чем у PayPal
✔ PayPal — как альтернатива
- Тоже работает в Латвии
- Но комиссии выше
- Не принимает платежи из РФ
Как подключить:
- В разделе Tipping Settings нажми Connect Stripe или Connect PayPal.
- Пройди регистрацию Stripe (займёт 5–10 минут).
- Укажи свой латвийский IBAN (Swedbank).
- Подтверди личность (паспорт/ID-карта).
После этого твоя страница донатов будет принимать платежи со всего мира.

4. Настрой страницу донатов
Всё в том же разделе Tipping Settings:
- Tip Page URL — твоя ссылка на донаты
- Minimum Tip Amount — минимальная сумма
- Currency — выбери EUR
- Message Length — длина сообщения донатора
- Alerts — включи оповещения

5. Подключи оповещения в OBS
- В левом меню StreamElements открой Overlays.
- Создай новый Overlay или выбери готовый.
- Добавь виджет Alerts → Tip Alert.
- Скопируй ссылку Overlay.
- В OBS добавь Browser Source → вставь ссылку.
Теперь донаты будут появляться на экране.

6. Проверь работу
В разделе My Tips есть кнопка Send Test Tip — используй её, чтобы проверить:
- отображение оповещений
- звук
- анимацию
- работу Stripe/PayPal

💡 Важные нюансы для тебя (Латвия + международная аудитория)
✔ Stripe — лучший вариант
Он идеально работает в Латвии и выводит деньги прямо на Swedbank.
✔ Донаты из России не пройдут
Stripe и PayPal блокируют российские карты.
Поэтому для РФ тебе нужна отдельная ссылка (DonationAlerts / DonatePay / TON).
✔ Для Европы/США StreamElements — топ
Платежи проходят быстро, комиссии низкие, всё стабильно.
