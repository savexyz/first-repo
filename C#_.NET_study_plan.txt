Шаг 1. Убедись, что установлен нужный рабочий набор
Visual Studio устанавливается модульно. Чтобы писать на C# и ASP.NET Core, нужен Workload:
✔ Разработка для ASP.NET и веба
или
✔ Разработка для .NET
Если ты не уверен, установлен ли он:
- Открой Visual Studio Installer
- Найди свою Visual Studio Community
- Нажми Modify / Изменить
- Поставь галочку на:
- ASP.NET and web development
- .NET desktop development (желательно, но не обязательно)
После этого нажми Modify и дождись установки.

🟩 Шаг 2. Создай свой первый проект ASP.NET Core
- Запусти Visual Studio Community
- Нажми Create a new project
- В поиске введи: ASP.NET Core Web API
- Выбери шаблон ASP.NET Core Web API
- Нажми Next
- Введи имя проекта (например, MyFirstApi)
- Выбери .NET 8 (или .NET 7, если 8 нет)
- Убедись, что стоит галочка Use controllers (если хочешь MVC)
или убери её, если хочешь минимальный API
- Нажми Create
Готово — у тебя полноценный веб‑проект.

🟧 Шаг 3. Запусти проект
В правом верхнем углу Visual Studio:
- выбери профиль запуска: https или http
- нажми зелёную кнопку Start
Откроется браузер, и ты увидишь работающий API.

🟨 Шаг 4. Где писать код
В созданном проекте есть важные файлы:
Program.cs
Точка входа.
Здесь начинается приложение.
Controllers/
Папка с контроллерами.
Например, WeatherForecastController.cs.
appsettings.json
Настройки проекта.
Properties/launchSettings.json
Профили запуска.

🟦 Шаг 5. Попробуй изменить маршрут
Открой Program.cs и добавь:
app.MapGet("/hello", () => "Привет, Вячеслав!");


Запусти проект — теперь по адресу:
http://localhost:5000/hello


ты увидишь свой текст.

🟩 Шаг 6. Создай свой первый контроллер
- ПКМ по папке Controllers
- Add → Controller
- Выбери API Controller – Empty
- Назови, например: TestController
Внутри напиши:
using Microsoft.AspNetCore.Mvc;

[ApiController]
[Route("api/[controller]")]
public class TestController : ControllerBase
{
    [HttpGet("ping")]
    public string Ping() => "pong";
}


Теперь по адресу:
http://localhost:5000/api/test/ping


получишь "pong".
